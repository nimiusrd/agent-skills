# 評価ケース

Luna のスキルあり・なしを、同じ課題・実行環境で独立した一時コピーを使って比較する。実行担当には対象promptとfixtureだけを渡し、期待事項や採点用ファイルは渡さない。模擬ケースでは実際のGitHub投稿やGit履歴変更をしない。

実行担当には対象ケースのpromptと入力fixtureだけを渡す。スキルあり側には `evals/` を除外したスキルコピーを追加で渡し、本文中の評価ケース・採点資料へのリンクも除く。両条件とも `evals.json`、期待事項、このREADMEを含む採点資料、他ケース・他条件の結果を参照させない。スキルなし側にはスキル本文も渡さない。採点は実行担当と分離し、実行後の成果物と結果で行う。
